# 黑畫面緊急恢復指南

## ⚠️ 重要提示

如果您的系統只有一個物理螢幕，將 VDD 設置為主顯示器會導致物理螢幕變黑。本文檔提供多種恢復方法，**即使看不到屏幕也能操作**。

## 🚨 快速恢復方法（按優先順序）

### 方法 1: 鍵盤快捷鍵切換顯示模式 ⭐ 推薦

**這是最快的方法，不需要看到屏幕！**

1. **按 `Win + P`**（Windows 鍵 + P 鍵）
   - 不需要看到屏幕，直接按即可
   - 等待 1-2 秒讓菜單出現

2. **按 `→`（右箭頭）一次**，然後**按 `Enter`**
   - 這會選擇 "擴展" 模式
   - 物理顯示器應該會重新顯示

3. 如果還是不行：
   - 再按 `Win + P`
   - 按 `←`（左箭頭）一次
   - 按 `Enter`（選擇 "僅電腦屏幕" 模式）

**為什麼有效**: `Win + P` 會打開顯示模式切換菜單，即使主顯示器是虛擬顯示器，這個快捷鍵仍然有效。

### 方法 2: 使用命令行停用 VDD

**前提**: 您需要提前打開命令行窗口，或者通過遠程桌面連接。

```batch
# 找到 vddctl.exe 的路徑（通常在）
cd C:\Users\nate\repos\vdd\Windows-driver-samples\video\IndirectDisplay
IddSampleDriver\build\bin\Release\vddctl.exe deactivate
```

**或者使用完整路徑**:
```batch
C:\Users\nate\repos\vdd\Windows-driver-samples\video\IndirectDisplay\IddSampleDriver\build\bin\Release\vddctl.exe deactivate
```

### 方法 3: 使用遠程桌面連接

如果您有遠程桌面連接（RDP）設置：

1. 從另一台電腦連接到這台電腦
2. 遠程桌面會顯示在物理顯示器上（即使主顯示器是虛擬的）
3. 在遠程桌面中執行 `vddctl deactivate`

### 方法 4: 強制重啟電腦

如果以上方法都不行，可以強制重啟（**不需要看到屏幕**）：

#### 方法 4a: 使用鍵盤快捷鍵重啟

1. **按 `Ctrl + Alt + Del`**
   - 可能需要等待幾秒讓安全屏幕出現
   - 即使看不到屏幕，這個快捷鍵仍然有效

2. **按 `Tab` 鍵 3 次**
   - 這會移動到右下角的電源按鈕

3. **按 `Enter`**
   - 打開電源菜單

4. **按 `R`**
   - 選擇 "重啟"

#### 方法 4b: 使用命令行重啟（如果已打開命令行）

```batch
shutdown /r /t 0
```

#### 方法 4c: 使用物理按鈕（最後手段）

- **按住電源按鈕 5-10 秒**強制關機
- 然後重新按電源按鈕開機
- ⚠️ **警告**: 這是最後手段，可能導致未保存的數據丟失

### 方法 5: 使用安全模式

1. 強制重啟電腦（方法 4）
2. 在啟動時**按 `F8` 或 `Shift + F8`**進入安全模式
   - 不同電腦的按鍵可能不同，也可能需要多次嘗試
3. 在安全模式下，VDD 驅動不會加載，顯示器會恢復正常
4. 登錄後，可以：
   - 卸載驅動: `vddctl uninstall`
   - 或停用 VDD: `vddctl deactivate`

4. **使用測試腳本**

## 🔧 技術說明

### 為什麼會出現黑畫面？

1. Windows 將主顯示器設置為 VDD 虛擬顯示器
2. 虛擬顯示器無法在物理螢幕上顯示
3. 物理螢幕變黑，因為它不是主顯示器

### 為什麼 `Win + P` 有效？

- `Win + P` 是系統級快捷鍵，不依賴於當前主顯示器
- 即使主顯示器是虛擬的，這個快捷鍵仍然有效
- 切換顯示模式會重新配置顯示拓撲，讓物理顯示器重新顯示

### 為什麼重啟有效？

- 重啟後，Windows 會重新初始化顯示系統
- 如果 VDD 未設置為自動啟動，物理顯示器會恢復為主顯示器
- 即使 VDD 自動啟動，Windows 通常會優先使用物理顯示器

## 📞 需要幫助？

如果以上方法都不行：

1. 嘗試所有方法（特別是 `Win + P`）
2. 強制重啟並進入安全模式
3. 在安全模式下卸載驅動
4. 如果問題持續，可能需要重新安裝顯示驅動
