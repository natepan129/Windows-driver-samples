# Summary

Create complete OpenSpec-compliant specifications for VDD SDK v1.0 and two
change proposals for v1.1/v1.2 features and critical bug fixes.

Based on design document requirements and technical audit findings, this
establishes formal specification framework for all current and planned
capabilities.

   - Graceful deactivation with window migration

3. **vdd-display-configuration/** (257 lines)

   - Desktop position/location management
   - Primary display designation

   - Supported display mode enumeration
   - DXGI output discovery for fullscreen targeting
   - System information query

   - Orphaned state detection and cleanup
   - Driver health verification and restart
   - Display topology backup/restore mechanisms

## openspec/changes/fix-display-configuration-issues/ - Critical Fixes

**Purpose**: Fix 19 critical bugs identified in technical audit

**Scope**: 81 tasks across 4 phases (v1.0.1 → v1.2)

**Issues Fixed** (by severity):

### 🔴 HIGH RISK (4) - Black Screen Issues
1. SetDisplayConfig topology corruption (blind query-replay)
2. SetPrimary() doesn't actually set primary display
3. String-based device matching fails on localized systems
4. SetMode() incomplete DEVMODE structure causes rejection

### 🟠 MUST FIX (5) - Broken Functionality
1. EnumerateModes() ignores outputIndex parameter
2. SPDRP_HARDWAREID multi-string parsing (only checks first)
3. SetMode() modeInfoIdx validation missing
4. SetLocation() path consistency issues
5. Refresh rate fractional handling (59.94Hz → 59Hz)

### 🟡 SHOULD FIX (6) - Inconsistencies
1. State source inconsistency (IsActive vs GetMode)
2. DiUninstallDriverW flag contradiction
3. GetVersionExW deprecated API usage
4. Device name localization issues
5. EnumerateAdapters() string matching fragility
6. GetMode()/GetLocation() return stale cache

### 🟢 UX IMPROVEMENTS (4) - Robustness
1. Activation stabilization delay (polling vs fixed 500ms)
2. Unsigned driver error feedback
3. Permission hints for non-admin operations
4. Display configuration validation (SDC_VALIDATE)

**Files**:
- proposal.md (comprehensive issue catalog, timeline, risks)
- tasks.md (81 tasks organized by phase and priority)
- design.md (correct patterns for SetDisplayConfig, device ID, DEVMODE)
- specs/vdd-runtime-control/spec.md (2 MODIFIED requirements)
- specs/vdd-display-configuration/spec.md (3 MODIFIED requirements)
- specs/vdd-query/spec.md (3 MODIFIED requirements)

**Timeline**:
- Phase 1 (v1.0.1): Week 1-2 - Critical black screen fixes
- Phase 2 (v1.1): Week 3-4 - Functional fixes
- Phase 3 (v1.1): Week 5-6 - Consistency fixes
- Phase 4 (v1.2): Week 7-8 - UX improvements

**Status**: Validated ✅, Phase 1 urgent
